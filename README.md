# Krishnajith V Portfolio — Vue 3

A responsive six-section Vue 3 + Vite portfolio recreated from the supplied desktop/mobile reference images.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
npm run preview
```

## Structure

- `src/App.vue` — six portfolio sections and interactions
- `src/style.css` — responsive visual styling
- `public/images/` — supplied desktop/mobile WebP backgrounds

The layout uses the supplied artwork for desktop and mobile breakpoints, with responsive navigation, timeline, skill cards, project cards, counters, and contact links.
